## Career arc (backend → platform)

I got my start as a **Java backend developer building systems for a Minecraft
server** — a playground that turned into a serious apprenticeship in concurrency,
low-latency networking, event handling, and shipping resilient services that
thousands of players hammered in real time. That early obsession with making
backends fast, correct, and hard to break has followed me ever since.

From there I grew into a **backend software engineer and architect** with deep,
hands-on experience across a wide range of languages and stacks — **Java,
Kotlin, Go, TypeScript/Node.js, Scala, Groovy, Python, Rust, and C**. I've
designed and built **RESTful, gRPC, and RSocket APIs**, real-time **WebSocket**
services, identity and **authorization systems** (OAuth2/OIDC, SAML, JWT,
HashiCorp Vault), and event-driven backends on **Apache Kafka**. I'm equally at
home with **NestJS and Spring**, with **TypeORM** and
JPA, and with relational and NoSQL data stores — **MySQL, PostgreSQL, Oracle,
MongoDB, and Redis**.

Today I'm a **Specialist Platform Engineer**. I've moved up through junior
software engineer, DevOps-minded software developer, and now platform
specialist — automating and building the applications that run the whole
software-delivery lifecycle. I design scalable, observable systems end to end:
**Kubernetes** and containers, CI/CD on **GitHub** and GitLab, infrastructure as
code (Terraform, Ansible, Packer), and observability with **Prometheus, Grafana,
OpenTelemetry, and Jaeger**. I write the unit tests, own the pipelines, and care
that the whole thing stays fast, secure, and trustworthy.
